# 当前替代方案

状态：`MARKET_MAP / NOT_CUSTOMER_CONFIRMED`

## 1. 人工审核 + 群聊/表格

典型流程假设：出图师批量导出 → 资深设计师逐张查看 → 在群聊、表格或截图上反馈 → 出图师返工 → 负责人终审。

优势：

- 不需要采购；
- 能理解品牌语境和模糊审美；
- 最终责任明确。

弱点假设：

- 批量吞吐依赖资深审核人；
- 证据、标准、改判原因和返工版本易散落；
- 同类问题难形成可计算反馈；
- 审核耗时和错放率很难追溯。

VisionQA 的可替代边界：先替代“首轮筛选、证据结构化、返工指令和复审对比”，不替代最终人工发布责任。

证据：VisionQA PRD 已定义创建者、发布复核人、改判和版本链；但目标客户是否使用飞书/Excel/微信群以及耗时多少尚无访谈证据。  
置信度：`LOW-MEDIUM`。  
下一验证动作：重建最近批次并进行 60 分钟现场观察；不能只听流程概述。

## 2. 设计师/修图师/外包后期

公开锚点：[Pixelz](https://www.pixelz.com/pricing/) 面向电商品牌、零售商和摄影棚提供后期服务，公开 Professional 档起价约 `$0.95/图`、订阅约 `$75–95/月`，Enterprise 约 `$1,995/月`，另有定制 onboarding。

优势：

- 直接交付修改后的图片；
- 能处理裁切、背景、颜色、阴影和复杂后期；
- 市场已经接受“订阅 + 按图”的采购形式。

弱点：

- 这是后期生产服务，不是客户专属发布前判断系统；
- 每个错误都进入修图会产生可变成本；
- 是否保留原 SKU 结构、是否满足渠道和品牌标准仍需验收。

VisionQA 的位置：不是替代 Photoshop 或修图供应商，而是在返工前回答“改哪张、为什么、优先级、必须锁定什么”，并在返工后复审。

证据：Pixelz 公开产品与价格；VisionQA 产品基线明确“不做改图工具”。  
置信度：`HIGH`（替代方案存在），`LOW`（目标客户是否正在购买）。  
下一验证动作：访谈中追问当前外包单价、内部返工成本和拒单/返修 SLA，验证 QA 是否能减少不必要返工。

## 3. 在线 proofing / DAM / 工作管理

- [Filestage](https://filestage.io/pricing/)：免费档；Starter `€199/月`；Business `€329/月`，提供版本对比、审批、注释和 review agents。
- [Adobe Workfront](https://business.adobe.com/products/workfront/pricing.html)：提供内容反馈、审批、版本、移动 proofing 和安全签核，价格需询价。

优势：

- 版本、评论、审批和责任链成熟；
- 适合多利益相关方；
- 企业安全、集成和采购路径相对清晰。

弱点/推断：

- 通用工作流不等于服饰 AI 模特图的真人、摄影、材质、商品忠实度和商业模板判断；
- 如果客户核心问题只是“评论太散”，VisionQA 没必要替代成熟 proofing 工具；
- Filestage 已有图像与合规 agent，VisionQA 必须证明专业判断与修复闭环的增量价值。

VisionQA 的位置：可先做专业评估层并导出结果；不应在 MVP 阶段重建完整 DAM。

证据：两家公司官方功能和价格页。  
置信度：`HIGH`（能力存在），`MEDIUM`（专业空白是合理推断，尚未做逐项竞品测试）。  
下一验证动作：让 3 位已有 proofing/DAM 的客户用同一批 20 张图比较“当前工具 + 人工”与 VisionQA，记录新增价值和重复功能。

## 4. 平台上传后诊断与自动修图

[Google Merchant Center](https://support.google.com/merchants/answer/6324350?hl=en) 明确：不符合最低图片要求会被拒；图片需要准确展示商品，限制促销覆盖层、水印和 Logo，生成式 AI 图片要保留相关元数据。[自动图片改进](https://support.google.com/merchants/answer/12724659?hl=en) 可尝试移除文字、水印、覆盖层或 Logo。

优势：

- 规则与平台最终判定直接相连；
- 部分修复自动完成；
- 不需要另买通用 QA。

弱点：

- 发生在平台侧，通常较晚；
- 只覆盖该平台定义的要求；
- 不能证明符合企业品牌偏好，也不覆盖完整真人/摄影/材质判断；
- 自动改图可能不是客户想要的商业表现。

VisionQA 的位置：发布前、跨渠道、保留品牌模板和人工终审的预检层。

证据：Google 官方帮助页；[Amazon Seller Central 图片要求](https://sellercentral.amazon.com/seller-forums/discussions/t/13af96ea-6b07-4bf9-8dbe-a13292c2e3b1) 同样要求准确展示实际商品并限制文字/图形/水印。  
置信度：`HIGH`（平台规则存在），`LOW-MEDIUM`（跨境客户的真实拒绝频率和成本）。  
下一验证动作：收集 10 个脱敏的真实图片诊断/拒绝案例，统计 VisionQA 是否能在上传前准确提示。

## 5. 模型提供方自带安全与质量能力

优势：

- 接近生成入口；
- 调用链短；
- 对明显内容安全问题可能已覆盖。

弱点假设：

- 通用输出不绑定 SKU 参考、客户商业模板和可追溯人工改判；
- 模型更新会造成输出漂移；
- “生成得好看”不等于“允许发布”。

VisionQA 的位置：模型无关、规则版本化、客户校准、审计和人工终审。

证据：项目当前已建立 provider adapter、模型快照和审计方向；真实 Qwen canary 尚未执行，不能宣称增量准确率。  
置信度：`LOW-MEDIUM`。  
下一验证动作：同一 20–30 张盲测集对比“模型原生描述”与“VisionQA 契约 + 门禁 + 人工复核”的可执行性和危险误放率。

## 购买决策含义

VisionQA 不是与一个单品竞争，而是与“人工判断 + 协作工具 + 修图服务 + 平台诊断”的组合竞争。成交条件必须同时满足：

1. 目标客户有高频批量；
2. 首轮筛选或返工确实是瓶颈；
3. VisionQA 能进入现有流程而非强迫替换全部工具；
4. 专业判断的错误率在受控试点中可接受；
5. 价值大于新增复核和集成成本。

总体置信度：`MEDIUM`。  
下一验证动作：访谈时必须问“如果没有 VisionQA，你会增加人、买什么工具、外包还是接受风险”，用真正的替代预算来验证。
