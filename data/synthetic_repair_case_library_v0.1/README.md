# VisionQA 合成修图案例库 v0.1

日期：2026-08-27
证据等级：`SYNTHETIC_INTERNAL_TEST_ONLY`

本目录保存由内置 ImageGen 基于同一件灰色罗纹开衫真值和同一张虚构模特母版生成的受控缺陷图。它用于验证“发现问题、确认问题、判断修图边界、路由局修或重生成”的产品流程，不构成真实客户证据、模型有效性、商业采用或付款证据。

## 统一商品真值

- 暖浅灰细罗纹圆领长袖短款开衫。
- 前襟恰好四颗哑光深灰纽扣。
- 正确刺绣恰好一枚，位于穿着者左胸（画面右侧）。
- 穿着者右胸（画面左侧）无刺绣或装饰。
- 无口袋、无拉链、无品牌文字。

`SC-001` 已替换为 v2 单问题候选：除第五颗纽扣外，刺绣数量与位置符合真值。案例 `SC-002` 至 `SC-005` 沿用早期受控草图中的“双刺绣”已知错误，因此除各自主问题外仍包含这一固定基线错误。产品体验中必须把用户当前确认的唯一主问题与“其他已知问题”分开，不得据此报告单问题数据集准确率。
