# 商业模板评测协议 v0.1

> 目标模板：天猫 / 平台促销主图  
> 阶段：Phase 1 判据验证  
> 数据：53 套购买模板，不含真实投放绩效

## 1. 本轮回答什么

本轮只验证：

- 商业子指标能否被两名评审者稳定理解；
- 相对模板贴合度能否形成一致排序；
- 系统能否识别不可评估素材；
- 切换模板后只有商业层发生合理变化；
- 人工改判能否形成可追溯校准事件。

本轮不能回答：

- 是否提升 CTR、CVR 或 GMV；
- 模型是否达到生产准确率；
- 模板权重是否代表真实客户；
- 90 分是否可以自动发布。

## 2. 数据划分

| 集合 | 数量 | 用途 |
|---|---:|---|
| 锚点候选集 | 15 | 8 个高贴合、4 个边界、3 个不可评估 |
| 独立标注集 | 38 | 不展示初始标签，用于评审一致性 |

53 张均为模板种子。不可评估占位模板用于验证失败处理，不作为低分负例。

## 3. 标注字段

每名评审者必须独立提供：

1. `assessability`  
   `APPLICABLE / NOT_APPLICABLE / NOT_ASSESSABLE`
2. `template_fit_level`  
   `HIGH / MEDIUM / LOW`；仅适用于 `APPLICABLE`
3. 六项 0–100 子分  
   商品主体、卖点表达、促销层级、信息可读、点击动机、图位适配
4. `primary_strength`
5. `primary_gap`
6. `evidence_note`
7. `confidence`

禁止根据“我喜欢/不喜欢”直接下结论。每项必须绑定可观察事实。

## 4. 双人评审流程

```text
Reviewer A 独立标注
→ Reviewer B 盲标
→ 自动计算分歧
→ 只对分歧项裁决
→ 冻结 gold label v0.1
```

分歧触发条件：

- `assessability` 不一致；
- 贴合度跨越两个等级；
- 综合贴合度差值大于 15 分；
- 任一子项差值大于 20 分；
- 优势或差距证据互相矛盾。

裁决者不能简单取平均，必须记录采用哪条业务证据。

## 5. 评测指标

### 5.1 评审一致性

- `assessability`：Cohen's κ；
- `fit_level`：加权 Cohen's κ；
- 总分：MAE、Spearman ρ；
- 六项子分：逐项 MAE 与 Spearman ρ；
- HIGH/MEDIUM/LOW 分布；
- 不可评估识别一致率。

Phase 1 目标：

| 指标 | 目标 |
|---|---:|
| assessability κ | ≥ 0.80 |
| fit_level 加权 κ | ≥ 0.70 |
| 总分 MAE | ≤ 10 |
| 总分 Spearman ρ | ≥ 0.75 |
| 不可评估一致率 | ≥ 95% |

这些是协议目标，不是当前结果。

### 5.2 跨模板差异

对锚点集同时运行：

- 天猫 / 平台促销主图；
- 品牌旗舰主图对照模板。

验证：

- 商业总分与子项可以变化；
- 真人、摄影、材质分保持不变；
- Blocker 门禁保持不变；
- 差异能够由模板判据解释，而不是随机漂移。

### 5.3 校准日志

检查每次人工改判是否保留：

- 客户、模板与画像版本；
- 系统原分、原等级；
- 人工结论与证据；
- `CAPTURED / REVIEWED / ACCEPTED / REJECTED / PROFILE_APPLIED` 状态；
- 操作者与时间；
- 应用后的画像版本。

单次事件不得直接更新客户画像。

## 6. 通过条件

进入真实模型小样本前，至少满足：

- 15 张锚点完成双人复核与裁决；
- 38 张独立集完成盲标；
- 一致性达到目标或形成明确修订计划；
- 不可评估规则稳定；
- UI、Schema、标注表和 D1 字段使用同一套模板版本；
- 购买模板始终标注为“无投放绩效证据”。

## 7. 下一阶段新增数据

真实商业验证至少需要：

- 同一 SKU 的修改前/后版本；
- 实际使用渠道与图位；
- 人工最终选择；
- 可选 CTR/CVR、收藏、停留或转化信号；
- 品牌规范和禁用项。

在这些数据到位前，不调整自动发布阈值。
