# VisionQA 商业模板独立第二评审包 v0.1

## 评审目的

验证“天猫 / 平台促销主图”商业价值评分是否具有稳定的人类判断基础。本轮不是让评审者确认已有结论，而是进行一次独立盲评。

## 请评审者使用

1. 打开 `anchor_blind_contact_sheet_v0.1.jpg` 查看 15 张待评图片。
2. 阅读 `second_reviewer_brief_v0.1.md` 的判断口径。
3. 在 `second_reviewer_response_template.csv` 中填写结果。
4. 将填写后的 CSV 原样返回。

预计耗时：20–30 分钟。

## 重要限制

- 不要向评审者展示 `initial_labels_v0.1.csv` 或带初评分的锚点图。
- 不要根据商品真实性、实拍真实性或投放效果作结论；这些是已购买模板素材，本轮只评估其对目标平台商业表达标准的适配性。
- 如果图片缺少足够信息，应标记为 `NOT_ASSESSABLE`，不要勉强给出商业分数。

## 返回要求

只需返回填写完成的 `second_reviewer_response_template.csv`。项目组收到后会自动计算一致性、边界偏差和模板修订项。
