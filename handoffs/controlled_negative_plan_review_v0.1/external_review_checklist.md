# LOW 受控负例计划｜外部创意审查清单 v0.1

状态：`PLAN_ONLY_AWAITING_EXTERNAL_APPROVAL`

## A. 全局门禁

请逐项勾选：

- [ ] 8 个 parent 均属于完整的天猫 / 平台促销主图，而不是空模板或跨渠道海报。
- [ ] 每个 variant 只有一个主要商业失败。
- [ ] 修改动作是业务中可能出现、且普通设计师能够理解的失败。
- [ ] 修改不是纯粹的审美偏好，也不是为了让画面显得“故意很丑”。
- [ ] 所有商品、人物、材质、价格、优惠条件和品牌事实均被锁定。
- [ ] 任何操作均不新增“新品、舒适、品质”等无来源商品声明。
- [ ] 任何操作均不复制优惠券、不增加优惠入口数量、不创造叠加承诺。
- [ ] 允许的次级指标变化范围合理，没有用一个操作同时破坏多个维度。
- [ ] 8 个方向足以用于测试商业评分的方向敏感性。
- [ ] 本批可以在内部研发环境制作，并标记为 `SYNTHETIC_CONTROLLED_NEGATIVE`。

如果任一红线项无法勾选，应停止全批制作或逐行标为 `REWORK / REJECT`。

## B. 逐张审查问题

对 `proposed_variants.csv` 每一行确认：

1. parent 是否适合作为该失败方向的基准？
2. 唯一操作是否足够具体、可重复？
3. 目标主指标是否选对？
4. 预期主指标至少下降 10 分是否合理？
5. `allowed_secondary_metrics` 是否过宽？
6. 锁定项是否遗漏？
7. 是否可能引入商品事实、人体、材质、价格或合规新问题？
8. 外部评审员看到 parent / variant 盲图时，能否仅凭图片理解这项商业失败？

## C. 必须拒绝的情况

- 修改价格、折扣、优惠门槛或活动日期；
- 创造不存在的商品功能、材质或品牌声明；
- 使用“新品、舒适、品质”等未经来源素材支持的替代文案；
- 复制优惠券或其他优惠元素，造成新增优惠或叠加承诺；
- 改变人物身份、人体结构、商品颜色、版型或纹理；
- 同时缩小主体、遮挡主体、降低对比等多个主要动作；
- 只是改变个人偏好的颜色或风格；
- 让图片不可评估，而不是形成可评分的完整 LOW；
- 输出带有真实客户失败、真实 CTR/CVR 或生产 gold 的错误声明。
