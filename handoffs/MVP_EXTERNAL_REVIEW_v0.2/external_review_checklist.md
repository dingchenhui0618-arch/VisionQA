# 外部审查清单

## A. 产品价值而非技术炫技

- [ ] 目标 ICP 是否限定为高频批量、重复人工复核、有返工成本的服饰电商团队？
- [ ] 是否有清楚的“人工审核现在如何做”的访谈问题，而非凭空假设？
- [ ] 是否把价格写成待验证梯子，而不是已知市场价格？
- [ ] 是否只保留一个核心任务：候选图审核到返工反馈闭环？

## B. 端到端闭环

- [ ] 可在单次会话完成候选图输入、结果阅读、人工确认或改判、反馈保存和试点指标提取。
- [ ] 分数、门禁、四项 Skill、证据、商业判断和修复 Prompt 均可见。
- [ ] Blocker 或上下文缺失不会被高分覆盖。
- [ ] Prompt 复制和人工改判能产生可追溯事件。

## C. 诚实披露和数据治理

- [ ] Fixture、本地确定性回放、未标定、未调用模型在每个关键结果处可见。
- [ ] 没有“自动发布安全”“提升转化”“节省 X%”等未经验证的表述。
- [ ] 87 张客户素材没有被上传、复制到项目外或用于外部模型调用。
- [ ] 外部审查只使用已获授权的演示图片。

## D. 技术和体验

- [ ] `npm test` 通过。
- [ ] 浏览器本地候选图入口支持格式、大小和错误状态。
- [ ] 键盘路径、焦点状态、移动端降级和文字对比度可用。
- [ ] D1 不可用时，页面明确说明反馈仅保存于本浏览器。

## E. 进入下一阶段的门槛

- [ ] 至少 12 次问题访谈，其中 6 次概念测试。
- [ ] 至少 3 份带金额试点提案，至少 1 笔真实付款才可提高 WTP 置信度。
- [ ] 真实模型前必须取得授权配对图、人工结论、返工版本和 gold set。
- [ ] 没有达成上述门槛时，不做 P1 集成、自动发布或多租户开发。
