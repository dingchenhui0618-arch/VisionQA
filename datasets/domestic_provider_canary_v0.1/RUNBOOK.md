# 国产视觉模型 Canary 运行手册 v0.1

## 状态

本包仅完成数据准备，当前为 `NOT_RUN`。没有调用模型，没有生成外网地址，也没有复制原始图片。

## 调用前五道门

以下条件必须全部为真，否则停止：

1. 隔离 staging 已就绪，能够产生可追踪的 evaluation ID；
2. 图片只能通过私有、短期、自动过期的 URL 交付，禁止公开 URL；
3. Provider、固定模型版本和数据处理条款已由治理角色批准；
4. 预算单价可验证、五张批次成本已计算且不超过所有者批准上限；
5. 运行器完成 payload allowlist 检查，gold 标签和本地元数据不会外发。

## 固定运行顺序

1. `CANARY-01 / CT-030`：先验证标准可评分路径和结构化输出。
2. `CANARY-02 / CT-012`：验证高信息密度、促销层级、移动端可读性和修复 Prompt。
3. `CANARY-03 / CT-024`：验证无模特场景不会触发虚假人体问题。
4. `CANARY-04 / CT-044`：验证 `NOT_APPLICABLE`，不得产生商业分。
5. `CANARY-05 / CT-035`：最后验证 `NOT_ASSESSABLE` 或人工复核，绝不能静默通过。

不得并发运行首个 canary。前一张的 schema、审计记录和门禁结果通过后，才能发送下一张。

## Provider 请求仅允许携带

- 临时匿名的 `canary_run_item_id`；
- `template_id` 与 `template_version`；
- response schema 版本；
- 输出语言；
- 私有短期图片 URL；
- 不含 gold 结论的统一系统 Prompt。

不得发送：

- 原始本地路径、原始文件名、集合 manifest；
- 人工 assessability、等级、总分、六项子分、优缺点和证据；
- 授权确认人的身份和源文件元数据；
- 密钥、token、账户标识或任何无关个人数据。

## 单项通过条件

- `CT-030/012/024`：返回可解析 schema、明确证据、六项分数和可复制修复 Prompt；不得虚构画面事实。
- `CT-044`：优先返回 `NOT_APPLICABLE` 并说明渠道不匹配；所有商业分字段必须为空。
- `CT-035`：返回 `NOT_ASSESSABLE` 或明确人工复核；所有商业分字段必须为空，不得 PASS。

## 立即停止条件

- 任一调用前门禁不是 APPROVED；
- 文件缺失、大小不符或 SHA-256 不符；
- URL 为公开、长期有效或无法确认过期；
- 请求包含 gold 或禁发字段；
- 无法得到可核验的成本预估，或预计费用超过批准上限；
- 连续两次 schema 解析失败；
- `CT-044` 或 `CT-035` 被硬打商业分；
- `CT-035` 被静默 PASS；
- 发现未批准的数据留存、训练使用或再分发。

停止后不得自动重试、不得换模型绕过，应保存脱敏错误证据并交 CTO/治理角色裁决。

## 预算占位

当前没有调用，也没有费用。正式运行前填写：

`预计批次成本 = 5 ×（单图输入费 + 封顶文本输入费 + 封顶输出费）`

Provider、固定模型版本、输入/输出单价、token 上限和所有者批准预算均为必填项。
