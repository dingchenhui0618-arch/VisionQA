# VisionQA 设计系统 v0.2

## Direction

浅色、单色中性基底、真实图片主导的专业视觉工作台。Apple 式精确与克制作为质量基线，同时保持审核工具需要的信息密度。设计参数：变化度 5、动效 3、信息密度 6。

## Palette

- Canvas: `#f4f5f6`
- Surface: `#ffffff`
- Ink: `#101114`
- Muted: `#686c74`
- Divider: `#dde0e5`
- Accent: `#2563eb`
- PASS: `#197a43`
- REVIEW: `#ad7610`
- REJECT: `#a93636`

状态必须使用文字与色点共同表达，不得只依赖颜色。

## Type

使用 Geist 与系统中文无衬线回退。产品标签、按钮和数据采用固定字号层级；ID、版本号和追踪号使用等宽字体。

## Spacing

4pt 基础尺度：4、8、12、16、24、32、48、64。

## Shape

- 控件圆角 8px。
- 有明确容器层级的面板使用 12px 圆角。
- 胶囊形状只用于分段筛选和紧凑状态。
- 优先使用分隔线和留白，不堆叠无意义卡片。

## Layout

- 客户路径：历史参考、客户画像、批次评分、筛选下载四步连续工作流。
- 主工作台：筛选栏、图片网格、稳定的动态 Inspector。
- 证据页：缩略片条、主图、证据与 Prompt 详情。
- 平板采用两列，手机采用单列并保留全部核心操作。

## Decision hierarchy

1. 候选图片。
2. 0 至 100 综合分。
3. 与分数并列的 Gate，确认 Blocker 时优先于分数。
4. 四大 Skill 分项，商业价值权重 35%。
5. 中文证据与可复制优化 Prompt。
6. 人工改判和审计记录。

## Motion

状态切换使用 150 至 250ms 过渡，不使用装饰性入场动画，并尊重减少动态效果设置。

## Bans

不使用渐变、玻璃拟态、通用 AI 紫、巨型圆角卡片、装饰图表、嵌套卡片、图片化文字和只靠颜色表达的状态。
