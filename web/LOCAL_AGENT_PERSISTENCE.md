# 本地商品对话持久化（2026-09-14）

## 黑白主题与对话内修图（后续迭代）

- 顶栏提供黑白主题按钮，localStorage 仅保存主题选择；不对商品图片应用反色或滤镜，手机端同样保留入口。
- 筛查后在对话中选择图片、原图或已完成修正版作为母版，拖动框选或输入百分比，明确确认后提交一轮修正。
- 对比展示每一轮实际输入与输出；历史版本保留，用户可选择任一已完成版本继续。三项人工确认绑定具体版本，切换版本不能继承放行。
- 网络结果不明确时保留同一提交编号；服务端校验重放内容、同项目并发和母版归属。失败释放额度，成功计次沿用原账本。
- 每轮绑定原筛查批次的参考图，而不是后来新建批次；规划记录也按修图任务读取。移除按示例文件名加载预制修正版的旧路径。
- 实现与零网络测试不证明真实改图质量。实际浏览器视觉/点击、真实模型端到端与费用对账仍待验收；未部署线上。

## 续作：对话内素材与筛查

- 商品项目确认后，`/agent` 内嵌参考图/待检查图上传、鉴权缩略图、勾选范围、显式图片发送同意和筛查结果。
- 每次逐文件 PUT；成功素材可从项目恢复，失败文案提示只重选失败文件。允许 1–4 张参考和 1–10 张候选；不静默丢弃超限选择。
- 后端阻止同一项目并发筛查和同租户跨商品图片混用；列表不返回对象存储路径或图片字节。
- 移除客户筛查接口按文件名返回示例结论的旧路径。示例素材也必须实际评估，不能把预设标签当模型诊断。
- 结果可填入当前对话讨论，不会自动发送文字或执行修图。实际修图仍明确指向完整工作区；下一步接入对话内修正与交付。
- `6300/agent` HTTP 200 且包含新能力文案；真实浏览器点击、响应式视觉验收及真实模型结果仍未验证。没有付费模型调用或线上部署。

仅适用于 localhost 原型。启用条件为 `VISIONQA_AGENT_LOCAL=true` 且非 production；不部署、不改变线上存储。左上角品牌保持 VisionQA。

## 已实现

- `work/local-agent-state/` 保存商品对话、项目关联、账号会话哈希、图片字节、筛查/修图记录、额度及预算预留；目录在 Git 忽略范围内，不是 public 静态资源。
- JSON 快照先写临时文件并 fsync，再原子替换。损坏或不兼容的数据失败关闭，不自动清空账号。
- 同一商品对话重复确认只关联一个项目；待确认计划可恢复，不重新调用规划模型。
- 修图中断恢复时释放冻结额度；筛查中断标记失败，不自动重发任何付费请求。
- 对话保存完整来源历史，上限 40 轮或 24000 字；达到上限明确提示，不静默截断。尚未实现用户确认的摘要压缩。
- 预算在请求前预留并保存，重复 record 不重复累计。金额是估算，不是供应商对账金额。

## 边界与下一阶段

- 这是单服务进程的本地原型，不能多个进程共写同一目录；不是数据库事务、分布式锁或生产存储方案。开发热更新期间避免进行真实付费任务，需另验 HMR 中断恢复。
- 本次改动前仅存在于内存且已丢失的数据无法恢复；旧会话失效时需重新进入本地体验。不得删除存储文件来绕过预算。
- 新预算文件不能追溯此前已花费用。真实模型验收前应核对已有调用/账单并确定剩余额度，不把新计数当作全历史消费。
- 图片仍受原有七天过期和项目删除规则管理；快照是本机私有数据，不加密，不可作为公开附件或提交到 Git。
- 下一步：把素材上传、问题确认与筛查接入当前对话，再接修图、前后对比和多轮版本选择。当前仍有旧工作台入口，尚未达到对话内全流程闭环。
