# VisionQA 产品上下文

## Register

product

## Platform

web

## Users

主要用户是已经使用 AI 制图的服饰电商美工、视觉负责人和负责最终验收的运营。他们先提供真实商品白底图，再提交 AI 模特草图，完成问题定位、修正、前后复验和清晰度交付。

## Product Purpose

VisionQA 是服饰电商 AI 模特图修正与交付工作台，不是批量打分器，也不是通用文案或一键生图工具。

核心链路：`商品真值 → AI 模特草图 → 问题诊断 → 修正与复验 → 4K 交付`。

## Four-step Workflow

1. 商品真值：上传白底图、官方确认稿、SKU 和不可修改属性。
2. AI 模特草图：同一 SKU、同一用途，建议 1 张，最多 3 张。
3. 问题诊断：检查商品漂移、人体异常、遮挡、材质失真和非目标区域变化；评分退到诊断细节。
4. 修正与交付：建立 Repair Job、上传改图结果、完成前后复验，并生成本机 4K 尺寸文件与处理凭证。

营销内容能力保留为后续可选延展，不再出现在当前主导航或核心交付路径。

## Authentication Boundary

`/workspace` 首屏提供登录界面和内部预览入口。正式账户认证、密码保存、找回密码和权限系统尚未接入；界面不得暗示认证成功或真实账号安全能力。

## Current Phase

- 服务优先，产品化证据不足时不扩展为公开 SaaS。
- 只处理服饰电商 AI 商品图，不扩品类。
- 自动放行关闭；真实结果必须人工终审。
- 模特母图不承担促销表达；缺少价格、优惠、CTA 或商业贴字不得被判为缺陷。
- 当前 4K 输出是本机高质量尺寸重采样，不冒充真实 AI 细节重建。
- 商品链接尚未抓取时只记录为输入，不能冒充已解析的 SKU 事实。
- 博主部分先输出画像；真实账号必须联网或人工核验来源、检索日期和授权。
- 商品表达使用 `product-expression-v0.1`；改图任务使用 `repair-job-v0.1`；营销交付使用 `marketing-delivery-pack-v0.2`。

## 2026-08-20 商品表达与营销智能体

- `product-expression-v0.1` 已从展示定义升级为运行时契约：固定六维权重、逐项证据与来源引用、不可评估状态、SKU Gate、未知项和强制人工终审。
- 旧版 `evaluation-result-v0.3` 只迁移具有直接对应证据的视觉重心、商品识别和场景适配；原商品一致性等维度不得补写历史分数。
- 营销交付改为本地受控智能体链路。未运行智能体前，界面不再把预置文案显示为生成结果。
- 每条营销输出附事实编号；核心输入缺失或出现无来源声明时，状态为 `NEEDS_INPUT` 或 `BLOCKED_UNSUPPORTED_CLAIM`。
- 当前没有接入外部 LLM、联网达人检索或自动发布，真实模型接入需另行确认供应商、预算、数据范围与留存策略。

## 2026-08-20 L2 领域智能体推进

- 在原有事实工作流外增加真正的 Agent Loop：Provider 可以根据观察结果逐步选择工具，而不是一次性返回模板内容。
- 当前用非模型测试 Provider 跑通四个工具和停止条件，界面展示每次决策、工具返回与最终停止原因。
- `UNKNOWN_TOOL / PROVIDER_ERROR / MISSING_DRAFT / MAX_STEPS` 均失败关闭；自动发布和自动放行继续关闭。
- L2 “运行框架就绪”与“真实模型有效”严格分开。后者需要 API Key 接入、真实输出评审和可重复的质量测试。
- 用户已授权本地项目及桌面相关素材的读取测试；支付动作和 API Key 接入仍需单独确认。
- 首选真实营销 Provider 已确定为千问百炼；固定 `qwen3.7-plus-2026-05-26`，只允许发送结构化事实，关闭搜索并限制单次运行最多 6 次模型决策。
- 当前只完成适配器和模拟响应测试。Key、付费调用与数据外传仍未获准，工作台继续明确显示“适配完成 · 等待授权”。
- 进入协助式 SaaS 前，至少需要 3 个真实付费批次及采用证据。

## Decision Policy

- 对外状态统一为 `PASS / CONDITIONAL_PASS / REWORK / REGENERATE / BLOCKED`。
- 综合分用于内部排序；Gate 可以覆盖分数。
- “商业价值”改为“商品表达效能”：视觉重心、商品识别、关键细节、原商品一致性、真实使用可信度和人群场景适配；促销信息不是默认评分前提。
- PASS 必须绑定参考范围，局部参考不得扩张为完整 SKU 结论。
- Logo 与字标优先使用官方资产确定性后处理。
- 生成式返工和视频生成必须检查商品结构及非目标区域漂移。
- 文案和脚本不得虚构折扣、库存、销量、评价、材质、功效或竞品结论。

## Evidence Boundary

工程可运行、模型有效、营销内容被采用、客户愿意付款是不同证据。示例素材、规则化草案、内部测试或点击不能替代真实模型评测、发布、采用、付款和再次提交。

## Brand Personality

像黑白影棚里的高级审片台：克制、精确、可信。界面退到黑白灰，让客户上传的多样素材成为最鲜明的颜色。

## Anti-references

- 不使用蓝色 SaaS 导航、通用 AI 紫、渐变或玻璃拟态。
- 不把所有上传、评分和交付内容堆在同一长页。
- 不用无意义 KPI 卡片、装饰图表和虚假实时状态。
- 不把示例项目、未抓取链接、博主画像或规则化草案冒充真实客户结果。

## Accessibility

状态同时使用文字、形状或色点；表单有可见标签；键盘焦点清晰；主要触控目标不小于 44px；移动端保留登录、上传、评审和交付能力；支持减少动态效果。
