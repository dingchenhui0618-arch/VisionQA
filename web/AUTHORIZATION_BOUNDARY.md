- 使用不产生费用、不需要新增账号或密钥、且不向第三方传输素材的本地工具。
- 在已确认的数据范围和预算内，后续对已接入 Provider 执行常规运行；授权范围变化时重新确认。

## 必须单独确认

1. 购买、充值、订阅、创建计费资源或其他支付动作。
2. 创建、输入、保存、轮换、启用或扩大 API Key 权限。
3. 首次启用某个外部模型 Provider 时，随 API Key 接入一并确认允许发送的数据类型和预算范围。

API Key 不粘贴到聊天、不进入仓库、日志、前端响应或测试快照。应用只暴露“是否已配置”，不暴露密钥值。
