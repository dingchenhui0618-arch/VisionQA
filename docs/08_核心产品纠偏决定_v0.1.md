# 核心产品纠偏决定 v0.1

> 日期：2026-07-28  
> 状态：已确认，立即生效  
> 影响范围：PRD、UI、Skill、评分、数据契约、评测和模型 Prompt

## 1. 为什么纠偏

UI 原型 v0.1 只呈现 `PASS / REVIEW / REJECT`、缺陷问题和证据，能够完成发布门禁，但没有完整表达策划书 v0.1 的核心产品：

- 缺少 0–100 综合分，无法批量排序和按阈值自动分级；
- 缺少可复制修复 Prompt，无法形成“发现问题 → 直接返工”的闭环；
- 服饰子规则没有映射回真人、摄影、材质、商业四大 Skill；
- 商业价值没有成为最高权重的独立输出。

因此，v0.2 中“`overall_score` 保持为空”的决定不再作为目标产品基线。保留其关于真实数据标定和硬门禁优先的安全约束。

## 2. 新的产品结果结构

```text
硬门禁
  ├─ Blocker：直接 REJECT，不允许被高分抵消
  └─ 不确定/资料不足：REVIEW

质量评级
  ├─ 综合分 0–100：排序、阈值分级、批量筛选
  ├─ 真人真实性 25%
  ├─ 摄影真实性 20%
  ├─ 材质真实性 20%
  └─ 商业价值 35%

行动输出
  ├─ 问题证据与业务影响
  ├─ 必须保持不变的商品信息
  ├─ 可复制修复 Prompt
  └─ 返工后复审
```

## 3. 分数和门禁的关系

- 分数回答“质量有多高、应该优先处理哪张”；
- 门禁回答“在当前证据下是否允许进入发布流程”；
- 高分但命中 Blocker 的图片仍为 `REJECT`；
- 没有 Blocker 但商业价值较低的图片可以是 `REVIEW` 或“优化候选”；
- 目标示例：综合分 ≥90 且无门禁可进入自动发布候选队列；
- 上述权重和阈值必须版本化，在真实授权数据标定前只能用于原型演示。

## 4. 四大 Skill 与服饰规则

服饰专属 taxonomy 不删除，而是作为四大 Skill 的垂直子规则：

| 四大 Skill | 服饰子规则示例 |
|---|---|
| 真人真实性 | 人脸、皮肤、头发、手部、肢体、姿态、抓握关系 |
| 摄影真实性 | 光影、透视、景深、曝光、噪点、镜头与空间关系 |
| 材质真实性 | 面料纹理、褶皱、垂坠、接缝、反射、透明与商品结构 |
| 商业价值 | 商品焦点、卖点可见、点击欲望、品牌感、版位适配 |

商品忠实度、文字 Logo、合规和可评估性继续作为跨 Skill 门禁或 scope，不应挤占四大评分维度。

## 5. 修复 Prompt 最低契约

每条 Prompt 至少包含：

1. 锁定项：不得改变的 SKU、商品结构、颜色、印花、Logo；
2. 修复项：具体问题、位置和希望达到的结果；
3. 真实感动作：人物、摄影和材质层面的修改要求；
4. 商业动作：需要强化的商品卖点和目标版位表达；
5. 负向约束：不得过度磨皮、过度锐化或引入新结构错误；
6. 关联证据：该 Prompt 解决哪些 observation；
7. 版本信息：生成该 Prompt 的规则与模板版本。

## 6. 评测增加项

- 分项分和综合分与人工评分的一致性；
- 批次排序质量，以及高分候选中的危险误放率；
- 商业价值评分的多人一致性；
- Prompt 复制/采纳率；
- 返工后目标问题解决率；
- 返工后新问题引入率；
- 修复前后分数变化与人工偏好的一致性。
