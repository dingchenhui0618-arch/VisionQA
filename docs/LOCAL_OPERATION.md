# 本地完整链路验收（进行中）

## 启动

在 `D:\VisionQA\web` 执行 `npm run dev:local`，打开 http://localhost:6300/ 。该命令明确启用本地持久化并关闭 Mock。服务端模型配置仍来自 Git 忽略的 `.env.local`，不复制密钥到前端。

`npm run dev:preview` 是独立 Mock 原型，不能用其模拟输出证明真实修图有效。

## 用户操作

1. 首页进入登录页，点击“填入测试体验口令”，接受邀请后进入 `/agent`。
2. 填写一个商品名称和目标，发送文字调用 DeepSeek 生成计划；确认后建立本地项目。
3. 上传 1–4 张真值和 1–10 张候选，勾选发送授权后开始真实筛查。
4. 选择问题图片、母版与局部区域，修改问题描述，确认后提交 Qwen 修图。
5. 等待完成，前后对比；三项人工复验通过后下载，或以此版本开始下一轮。

## 当前验证边界

- 浏览器实点已通过：测试登录 → `/agent` → 真实 DeepSeek 规划 → 确认创建项目 → 显示上传面板。
