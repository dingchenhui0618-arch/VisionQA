# 商业价值模板化决策 v0.1

## 结论

采纳商业顾问 Brief 的核心方向：

> 商业价值从模型通用审美判断，升级为绑定模板与客户偏好的相对评估。

但作以下产品级修正：

1. 保留 0–100 分，改为“相对模板贴合度分”，继续参与综合评分；
2. 将渠道、图位、品牌定位、商业目标和视觉调性拆为正交参数；
3. 单次人工改判只进入校准日志，经过复核与版本化流程后才能影响客户画像；
4. 商业模板变化不得改变客观三层 Skill 或确定性门禁；
5. 修复 Prompt 继续作为核心价值输出，但不把它单独定义为长期数据护城河。

## 首个模板

```yaml
  - promotion_conversion
  - selling_point_communication
  - click_motivation

```

选择原因：

- 当前 53 套素材高度集中于平台促销、活动价格、卖点标签和主图信息层级；
- 比“大牌旗舰”更贴合现有素材分布；
- 可以更快建立可观察、可标注、可复核的商业子指标。

## 素材身份

53 套素材为项目负责人购买的模板素材，并已允许：

- VisionQA 内部研发；
- 第三方视觉模型测试；
- 后续真实投放成品素材沿用相同许可口径。

它们是商业模板种子，不是真实投放绩效证据，也不是端到端视觉质检 gold set。

## 与既有产品基线的关系

商业价值仍是第四层 Skill，默认权重保持 35%。新的计算关系为：

```text
客观三层 Skill
+ 当前商业模板下的相对贴合度
→ 综合质量分

确定性 Blocker
→ 独立门禁，不受综合分抵消
```
