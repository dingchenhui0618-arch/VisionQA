# 需要创意总监提供的信息

以下输入按优先级排列。现阶段不要求一次全部准备完，先完成 P0。

## P0：开始首轮验证前必须提供

### 1. 选择首个垂直场景

请填写：

```text
目标客户：
素材类型：
具体发布渠道：
每天或每周审核量：
当前由谁审核：
审核一张图大约需要多久：
最严重的错误是什么：
```

建议候选：服饰电商团队的 AI 模特商品图发布前质检。

### 2. 提供视觉判断样例

建议先提供 20–30 张，不需要立刻达到 200 张：

- 5–10 张你认为可以直接发布的图；
- 5–10 张需要修改后发布的图；
- 5–10 张必须拒绝或重新生成的图。

每张图至少补充：

```text
结论：通过 / 人工复核 / 拒绝
最主要原因：
严重问题：
可以接受的问题：
你会如何修改：
```

请确认图片可用于内部研究与评测，并记录来源或授权状态。

### 3. 定义业务损失

请回答：

- 把坏图错放出去，可能造成什么损失？
- 把好图错误拦截，可能造成什么损失？
- 两者哪一种更不能接受？
- 人工复核可以承接多少比例的素材？

这些答案决定 A/B/C 阈值，而不是由模型自行决定。

### 4. 明确不可改变项

例如：

- 商品颜色、结构、Logo、包装文字；
- 人物身份或脸部一致性；
- 品牌视觉规范；
- 平台尺寸、留白、文字安全区；
- 法律、版权、广告与内容安全要求。

## P1：建立正式标注集前提供

- 至少一位额外标注者；
- 品牌规范或过往审核规则；
- 真实生产流程中的失败案例；
- 原图、原始 Prompt 和修改后结果（如可获得）；
- 现有审核耗时、返工率和通过率。

## P2：产品化前提供

- 目标用户访谈或试用反馈；
- 愿意付费的决策人和预算方式；
- 数据保存、删除与隐私要求；
- 需要对接的生成工具和工作流；
- 期望的处理量、成本和响应时间。

## 暂时不需要

- 完整品牌设计系统；
- 复杂账号与订阅系统；
- 大规模自训练模型；
- 视频、3D 和数字人的完整数据集；
- 一开始就收集覆盖所有行业的图片。
