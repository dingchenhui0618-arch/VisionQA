# Picset 公开体验对照与本地调整

## 登录后追加体验（2026-09-17）

用户登录后再次访问国内 `https://picsetai.cn/studio-genesis` 与国际 `https://picell.ai/zh-CN/studio-genesis`，页面已出现账号入口而非登录按钮。两站具有相似的任务分阶段结构；不能仅凭前端推定服务端实现相同。

- 国际站实际切换“自定义模块”，出现可选交付模块（主视觉、细节、场景、规格等）；这比要求用户自己写完整 Prompt 更便于表达交付目标。
- 国际服装页 `https://picell.ai/zh-CN/clothing-studio` 区分服装、模特、可选场景。素材角色应独立记录，不能把风格参考当商品事实。
- 国内画布实际点击“生成图片”打开空图片节点，显示配置与发送前积分，再打开 Skill 面板看到个人/专属入口。未点击发送，没有上传素材。该空节点可能留作当前账号草稿，未删除任何用户项目。
- 国际页展示 Nano Banana 2、国内页展示 Nova 2.0，均为界面标签；未验证实际后端模型。VisionQA 继续仅用 DeepSeek/Qwen，不照搬标签或路线。
- 没有触发生成、充值或读取账户凭据；输出修改/下载、画布执行顺序、实际效果和计费均未验证。未下载对方后端源码。

### 第二批本地落地

同一商品对话嵌入“素材 / 检查结果 / 修图与版本”三个视图。非当前面板保留挂载，避免切换清空选择与未提交修图要求；只有显式提交才执行。恢复已筛查商品默认展示结果，没有结果时显示实际下一步，而不是示例输出。

12 项相关测试、Lint、构建通过；1440/1024/390/375 无横向溢出，浏览器验证切换后修图要求/版本保留。只读既有本地结果；无新增模型质量证据。

## 观察与取舍

| 公开来源 | 界面事实 | VisionQA 的取舍 |

| https://picsetai.cn/studio-genesis | 输入、分析、确认规划、生成、完成分阶段；配置与结果分区 | 借鉴当前阶段明确可见；不把生成组图伪装为现成能力 |
