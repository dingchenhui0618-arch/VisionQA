# Picset 公开体验对照与本地调整

## 范围与证据

2026-09-17 使用真实浏览器访问官网、组图、风格参考、精修和画布。仅公开界面；没有注册、充值、上传商品资产或调用其模型。点击画布“生成图片”后跳到登录，因此生成质量、内部调度、实际成本与主体一致性未验证。未下载私有源码或复刻其素材。开发者工具能看到的前端不能还原服务端模型流程。

## 观察与取舍

| 公开来源 | 界面事实 | VisionQA 的取舍 |
| --- | --- | --- |
| https://picsetai.cn/studio-genesis | 输入、分析、确认规划、生成、完成分阶段；配置与结果分区 | 借鉴当前阶段明确可见；不把生成组图伪装为现成能力 |
| https://picsetai.cn/aesthetic-mirror | 风格参考与商品素材分开；生成前显示积分 | 保留商品参考与候选角色，提交旁保留真实费用提示；风格参考未来应是独立角色 |
| https://picsetai.cn/refinement-studio | 批量上传、精修要求和结果区域职责清晰 | 已完成素材折叠，问题图直接带缩略图，减少寻找素材与操作的距离 |
| https://picsetai.cn/canvas-studio | 图/视频/文本节点与工作流入口；生成要求登录 | 画布为未来专业模式候选，不替换当前商品对话主入口 |

官网包含产品一致性等绝对宣传，未独立验证，不转写为我们的保证。参考站不是开源仓库，本轮交付为公开行为分析与自主实现，不是下载其后端运行。

## 当前落地

1. 新建对话输入居中，发起后悬浮；切换新商品重置位置。
2. 素材在筛查完成后默认折叠，仍可展开查看、修改选择、重新筛查。
3. 结果缩略图 + 单问题 + 修图主动作；点击后定位修图区。
4. 精确坐标折叠，版本继续修正聚焦要求；下载禁用原因用明文说明。
5. 手机收起历史，费用说明留在输入框，不混淆文字规划与执行修图。

## 下一阶段建议（尚未实施）

保留单商品上下文作为统一入口，逐项接入“评审修图、成套商品图、视觉参考、脚本/视频”。通用边界为商品事实与素材角色 → 用户确认计划 → 有预算上限的执行 → 可追溯资产与版本 → 人工复验。模型仅用已授权的国内路由。不要先堆工具入口、节点画布和未接通按钮。

## 验证边界

本轮只做界面与已有数据回归，无新增付费模型调用，不动线上。桌面1440、平板1024、手机390/375分别检查空态相对定位和会话固定定位。模型效果仍沿用之前的未完成质量验收结论。
