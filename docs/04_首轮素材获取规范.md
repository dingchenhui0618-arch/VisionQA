# 首轮素材获取规范 v0.1

## 目的

首轮素材不是为了训练模型，而是为了回答：

> 在同一类真实业务图片中，我们能否稳定区分通过、人工复核和拒绝？

## 建议向电商团队获取什么

首轮只需要 20–30 组，优先选择服饰电商 AI 模特商品图。每组尽量包含：

1. 待审核的 AI 模特图；
2. 对应商品参考图，最好包含正面、背面和细节；
3. 原审核结论：通过、修改或淘汰；
4. 淘汰或修改原因；
5. 如果有，修改后的最终版本；
6. 图片使用渠道：主图、详情页、广告或社媒；
7. 图片来源和内部研究使用许可。

## 样本分布

- 5–10 组可以直接发布；
- 5–10 组需要人工复核或局部修改；
- 5–10 组必须拒绝或重新生成；
- 不要只给明显失败图；
- 不要只给同一个模特、商品或生成批次；
- 尽量包含团队真实遇到的边界案例。

## 每组最低标注

```text
sample_id:
业务结论: PASS / REVIEW / REJECT
最主要原因:
阻断问题:
可以接受的问题:
建议修改:
发布渠道:
标注人:
素材授权状态:
```

## 隐私与版权

- 首轮优先获取对方明确同意用于内部产品验证的图片；
- 不公开、不宣传、不上传到未经允许的第三方服务；
- 如图片包含未发布商品、真人肖像或品牌机密，先确认允许的处理方式；
- 无法确认授权的网络图片只能作为标准讨论参考，不进入正式评测集；
- 原始素材与标注分开保存，后续建立删除和访问规则。

## 如果暂时拿不到真实素材

可以先用 12–15 组自有或明确授权素材完成“标准试写”，但这些样本不能证明市场效果。拿到真实素材后必须重新做盲测，不能沿用已经看过并调过规则的图片作为最终测试集。
