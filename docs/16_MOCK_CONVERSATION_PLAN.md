## 不依赖真实模型的验收

1. 清晰区分 mock 与真实运行：本地开关关闭、生产构建及非本地主机均不能开放模拟入口；登录和退出不改变真实 beta 会话。
2. 点击主题、快捷填写、新对话都有可见反馈；客户端模块无加载错误；页面刷新恢复模拟对话。
3. 单商品完整链：创建 → 添加参考和候选 → 模拟筛查 → 选图 → 修改要求 → 确认计划 → 对比 → 三项人工检查 → 下载模拟记录。
4. 同一商品至少两张候选可逐一处理；不同商品的素材、要求、版本和确认状态不串联。
5. 模拟失败不新增版本、不扣额度；要求保留；重试只新增一个版本；快速双击无重复命令。
6. V1 → 以 V1 继续 → V2 → 以 V2 继续 → V3 的母版链可追溯；回到原图形成新版本，旧版本与人工确认记录保留。
7. 修改当前版本、查看历史版本及切换商品后，确认勾选不错误沿用；只有当前已确认版本可下载。
8. 浏览器刷新和关闭重开后图片及历史恢复；存储失败显示错误且不显示未落盘结果；多个标签页不能静默覆盖数据。
9. 网络检查无模型 provider、旧 local-agent tasks、素材上传或收费接口请求。示例图片的同源静态读取不属于模型调用。
10. 桌面与窄屏完整操作可达，长对话不遮挡输入框，键盘焦点、disabled 状态与错误提示可理解。

## Live port 后续迁移

商业与真实模型验证单独安排。模拟验收通过不自动授权接入收费 provider 或扩大图片用途。

1. 保留 `ConversationPort` 的 UI 边界，先补全真实 DTO：租户和项目归属、来源资产 ID、请求幂等键、全局/会话 revision、任务 ID、模型及 Prompt 版本、审核参考范围。
2. Live 状态由服务端权威保存，客户端不上传完整快照覆盖；每条命令校验归属、版本及阶段，失败关闭并支持可审计重试。
3. 单独实现 live adapter，复用现有质量内核与经验证的资产/任务接口。禁止把 mock cookie、data URL、脚本分类或模拟 reviewed 状态直接当作真实授权、质量结论或放行记录。
4. 上传前确认数据用途；真实返工绑定母版、目标区域、保持约束和非目标漂移检查。继续关闭自动放行，最终由人工确认。
5. 先使用契约测试替身验证鉴权、幂等、超时、失败恢复、来源链与额度一致性，再在另行授权的真实 SKU 上做端到端验收。
6. 真实测试分别记录工程可运行、模型有效、客户采用/付款证据；明确费用、成功率及质量的测量范围。
