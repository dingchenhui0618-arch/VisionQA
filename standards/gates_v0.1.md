# 服饰电商 AI 模特商品图发布门禁 v0.1

> 状态：内部草案，待真实客户素材验证  
> 适用场景：服饰电商 AI 模特商品图发布前质检  
> 核心原则：事实、结构、合规和可评估性问题优先于审美总分；严重问题不得被高分抵消。  
> 当前限制：尚无真实客户素材和线上返工数据。本文所有数值阈值与计数阈值均为待验证假设。

## 1. 输出结论

系统只输出以下三个发布决策：

- `PASS`：未发现阻断问题；在当前证据和标准下可进入发布流程。
- `REVIEW`：存在信息不足、判断不确定或需要人工确认/返工的问题。
- `REJECT`：存在阻断发布的问题，必须重新生成、重做或完成专项修复后复检。

`PASS` 不代表法律保证，也不代表商品一定高转化。

## 2. 判定优先级

```text
可评估性检查
    ↓
硬门禁检查
    ↓
重大/轻微缺陷聚合
    ↓
软评分与商业表现
    ↓
PASS / REVIEW / REJECT
```

优先级从高到低为：

1. 合规与安全；
2. 商品忠实度；
3. 人体完整性；
4. 文字与 Logo；
5. 可评估性；
6. 服装/材质与摄影物理；
7. 构图与商业表达；
8. 总分。

任何高优先级硬门禁命中后，不再允许总分改变结论。

## 3. 硬门禁

以下任一条件以足够置信度成立时，结论为 `REJECT`：

### 3.1 商品事实门禁

- 商品品类、款式、核心版型错误；
- SKU 的关键颜色、图案、印花或结构错误；
- 关键配件被增删、替换或生成错位；
- 商品出现不可接受的融化、断裂、穿插；
- 商品事实错误可能误导购买。

没有权威商品参考时，不得自动声称该门禁通过；应转为 `REVIEW` 或限制为“仅图内质量评估”。

### 3.2 人体完整性门禁

- 多肢、缺肢、肢体融合或断裂；
- 多指、缺指、手指融合；
- 明显不可能的关节方向、躯干结构或五官结构；
- 人体错误明显干扰商品展示或构成发布风险。

### 3.3 文字与 Logo 门禁

- 品牌名、Logo、商标或商品关键信息错误；
- 尺码、成分、功能等可能影响购买的信息错误；
- 关键文案乱码、错字或语义错误。

### 3.4 合规门禁

- 明确的平台禁限内容；
- 明显虚假、夸大或无法支持的商品表达；
- 高风险版权、商标、肖像或素材授权问题；
- 涉及未成年人、色情、仇恨、暴力或歧视等高风险内容。

合规项无法自动确认时，输出 `REVIEW` 并标注需法务或平台规范复核。

### 3.5 可评估性门禁

- 文件不可读取；
- 分辨率或清晰度不足以判断关键细节；
- 商品被严重裁切或遮挡；
- 对象对应关系不明确，无法判断被评估商品。

如果问题通过补充材料即可解决，则结论为 `REVIEW`；如果候选图本身不可用于发布，则为 `REJECT`。

## 4. PASS / REVIEW / REJECT 规则

### REJECT

满足任一条件：

- 至少 1 个已确认的 Blocker；
- 多个 Major 共同造成商品不可理解、明显不真实或必须重做；
- 合规风险达到禁止发布级别；
- 候选图本身不可评估且无法通过补充信息解决。

“多个 Major”的数量及组合规则待真实客户素材验证，不在 v0.1 中锁死。

### REVIEW

满足任一条件，且未达到 `REJECT`：

- 至少 1 个 Major；
- 存在疑似 Blocker，但模型置信度不足；
- 缺少商品参考图、SKU 不可改变项、品牌规范或渠道要求；
- 存在需要人工判断的合规、品牌或商业表达问题；
- Minor 聚集后明显影响发布质量；
- 模型之间或模型与规则之间结论冲突。

Major/Minor 数量、置信度和冲突阈值均待真实客户素材验证。

### PASS

必须同时满足：

- 可评估性检查通过；
- 无 Blocker；
- 无需人工确认的 Major；
- 商品忠实度已基于充分参考材料核验，或结论明确限定为“不含商品忠实度核验”；
- 文字、Logo 和合规检查在当前材料范围内通过；
- Minor 未达到影响发布的聚集程度；
- 模型置信度满足经验证的发布阈值。

在阈值尚未验证前，v0.1 禁止全自动直接发布；验证期内 `PASS` 默认进入 100% 人工复核。真实客户数据达到预设门槛后，才评审是否改为抽样复核。

## 5. 软评分 Rubric

软评分仅用于排序、解释和优化建议，不参与抵消硬门禁。

建议每个维度使用 0–4 锚点评分：

| 分值 | 统一含义 |
|---|---|
| 4 | 符合当前发布目标，无可见问题 |
| 3 | 有轻微问题，但不显著影响发布 |
| 2 | 有明显问题，需要人工复核或修改 |
| 1 | 严重影响质量，通常需要大幅返工 |
| 0 | 该维度不可接受；若属于硬门禁则直接 REJECT |

评分维度：

1. 商品忠实度；
2. 人体完整性；
3. 服装与材质可信度；
4. 摄影物理一致性；
5. 构图与商业表达；
6. 文字与 Logo 准确性；
7. 合规性；
8. 可评估性。

说明：

- 商品忠实度、文字与 Logo、合规性、可评估性更适合作为门禁状态，不建议仅以连续分数表达。
- 如需生成 0–100 总分，应由已验证的数据标定各维度权重；当前不得使用策划书中的固定权重作为发布依据。
- `overall_score` 必须与 `decision` 分离。例如：总分 88，但命中 Logo 错误，结论仍为 `REJECT`。

## 7. 待验证阈值

以下项目必须使用真实客户素材和多人标注结果标定：

- Blocker 自动判定的最低置信度；
- Major/Minor 聚集触发 `REVIEW` 或 `REJECT` 的数量；
- `PASS` 的模型置信度；
- 人工抽检比例；
- 各维度权重及 0–100 分映射；
- 不同品类对商品结构错误的容忍度；
- 不同渠道、版位和品牌对构图商业表现的最低要求；
- A 级误放率、返工率和漏检率的上线阈值。

在上述阈值完成验证前，系统只能作为审核辅助，不应代替最终人工发布责任。
