# Vision QA 四大 Skill 与服饰规则映射 v0.2

> 状态：可用于数据契约和试标的内部草案  
> 更新日期：2026-07-28  
> 适用范围：服饰电商 AI 模特商品图  
> 依赖：`taxonomy_v0.1.md`、`rubric_v0.1.md`、`gates_v0.1.md`

## 1. 目的

四大 Skill 是用户看到的稳定质量框架；服饰规则码是场景内可定位、可标注、可回归的子规则。

```text
四大 Skill（跨品类稳定）
  → 子指标（可评分）
    → 服饰规则码（可定位问题）
      → observation / evidence region（单图证据）
```

商品忠实度、文字 Logo、合规与可评估性属于跨 Skill 门禁或评估 scope。它们可以影响一个或多个 Skill，但不能被综合分抵消。

## 2. 四大 Skill

| Skill ID | 名称 | 默认权重 | 核心问题 |
|---|---|---:|---|
| `HUM` | 真人真实性 | 25% | 人脸、皮肤、头发、手部、肢体、姿态和接触关系是否真实可信 |
| `PHO` | 摄影真实性 | 20% | 光影、镜头、透视、景深、曝光和空间关系是否成立 |
| `MAT` | 材质真实性 | 20% | 皮肤、面料、褶皱、垂坠、接缝、反射和透明关系是否可信 |
| `COM` | 商业价值 | 35% | 商品是否突出、卖点是否清楚、是否有点击动机、品牌感和版位适配 |

每个 Skill 输出 0–100 分、可评估状态、证据引用和扣分原因。缺少必要材料时分数可以为 `null`，不得猜测。

## 3. 详细映射

### 3.1 `HUM` 真人真实性

| 子指标 | 服饰规则 | 说明 |
|---|---|---|
| 肢体完整性 | `HI-01`、`HI-03` | 多肢、缺肢、融合、断裂、比例或关节错误 |
| 手部真实性 | `HI-02`、`HI-04` | 手指数量、结构、抓握与衣物接触 |
| 面部真实性 | `HI-05` | 五官、瞳孔、牙齿、耳部 |
| 姿态与重心 | `HI-06` | 重心、动作自然度、穿着姿态 |
| 皮肤与发丝 | `HI-07`、部分 `PP-05` | 磨皮、发丝边缘、肤色与微纹理 |

门禁映射：

- 已确认的 `HI-01`、`HI-02` 或明确不可能结构：`REJECT`；
- 疑似 Blocker 或证据不足：`REVIEW`；
- 轻微皮肤和发丝问题只影响评分与修复 Prompt。

### 3.2 `PHO` 摄影真实性

| 子指标 | 服饰规则 | 说明 |
|---|---|---|
| 光影一致性 | `PP-01`、`PP-02` | 主光、投影、接触阴影 |
| 透视与空间 | `PP-03` | 尺度、空间关系、镜头透视 |
| 景深与焦点 | `PP-04` | 景深遮罩和主体清晰度 |
| 曝光与色彩 | `PP-05` | 曝光、白平衡、肤色 |
| 合成边缘 | `PP-06` | 抠图光边、背景穿帮、边缘融合 |
| 成像质感 | `PP-07` | 噪点、锐化、色带、压缩与手机摄影感 |

明确空间不可能可以触发门禁；其他问题通常进入评分与优化。

### 3.3 `MAT` 材质真实性

| 子指标 | 服饰规则 | 说明 |
|---|---|---|
| 商品结构连续性 | `GM-01`、`PF-03`、`PF-05` | 衣片、接缝、领口、袖口、结构件 |
| 纹理与图案 | `GM-02`、`PF-02` | 编织、重复纹理、印花连续性 |
| 褶皱与垂坠 | `GM-03`、`PF-06` | 重力、受力、姿态与面料响应 |
| 材质类型 | `GM-04` | 棉、丝、皮革、针织等属性表达 |
| 反射与透明 | `GM-05` | 高光、反射、透明和衬里关系 |
| 微观质感 | `GM-06` | 塑料感、过度平滑和锐化 |

`PF-*` 仍然是商品事实规则。与参考图明确冲突时先触发商品门禁，再影响 `MAT` 解释；不得只扣分。

### 3.4 `COM` 商业价值

| 子指标 | 服饰规则 | 可观察证据 |
|---|---|---|
| 商品焦点 | `CC-01`、`CC-02` | 主体面积、遮挡、背景或人物抢焦 |
| 卖点表达 | `CC-01`、`CC-05` | 领口、腰线、面料、版型等关键卖点是否可见 |
| 构图与版位 | `CC-03` | 裁切、留白、视线引导、目标图位安全区 |
| 品牌一致性 | `CC-04`、`TL-04` | 色彩、造型、背景与品牌规范的可见冲突 |
| 点击动机 | `CC-05`、`CC-06` | 姿态、视觉记忆点、商品层级和差异化 |

商业价值不得只写“高级”“好看”或“有氛围”。每个判断必须关联目标渠道、品牌材料或可观察画面事实。

品牌规范或目标版位缺失时：

- `assessability` 记录 `AS-05`；
- `COM` 标记为 `LIMITED`；
- 可以给有限场景分，但不得声称符合品牌或正式版位。

## 4. 跨 Skill 门禁

| 门禁 | 规则 | 处理 |
|---|---|---|
| 商品事实 | `PF-01`–`PF-05` | 明确 Blocker 直接 `REJECT` |
| 人体结构 | `HI-01`–`HI-05` | 明确 Blocker 直接 `REJECT` |
| 文字与 Logo | `TL-01`–`TL-04` | 权威材料确认错误后 `REJECT` |
| 合规 | `CO-01`–`CO-05` | 按已提供规则阻断或转专业复核 |
| 可评估性 | `AS-01`–`AS-06` | 不可评估、资料不足或 scope 限制 |

## 5. 计分原则

1. 先执行门禁，再计算适用 Skill 分；
2. Skill 分用于排序、解释和优化，不抵消门禁；
3. 默认综合分：

```text
HUM × 0.25 + PHO × 0.20 + MAT × 0.20 + COM × 0.35
```

4. 任一 Skill 不可评估时，`overall_score` 默认保持 `null`；如未来允许归一化计算，必须使用独立策略版本；
5. 当前原型分档为 `90–100 PASS 候选 / 70–89 REVIEW 优化 / 0–69 REJECT 返工`，只用于演示；
6. 权重、锚点和阈值必须分别记录 `score_policy_version` 与 `threshold_policy_version`。

## 6. Prompt 映射

每条 observation 进入修复 Prompt 时必须标记：

- `skill_id`；
- `issue_code`；
- `evidence_region`；
- `repair_action`；
- `locked_attributes`；
- `negative_constraints`；
- `strategy`：`LOCAL_EDIT`、`REGENERATE` 或 `MANUAL_REVIEW`。

Blocker 默认不应只生成“美化建议”，必须明确重新生成、局部重绘或人工核对商品事实。

## 7. 待验证项

- 四大 Skill 内部子指标权重；
- 0–4 旧锚点映射到 0–100 的方式；
- 商业价值多人标注一致性；
- `AS-05` 下有限商业分的上限；
- Major/Minor 聚合规则；
- Prompt 是否解决目标问题且不引入新问题。
