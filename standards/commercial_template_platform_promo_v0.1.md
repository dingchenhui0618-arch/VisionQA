# 商业价值模板：天猫 / 平台促销主图 v0.1

> 状态：Phase 1 验证草案  
> 模板 ID：`platform_promotion_main_image_v0.1`  
> 数据来源：53 套已授权购买模板  
> 适用范围：服装服饰类平台促销主图、活动主图、直播货架主图

## 1. 设计原则

商业价值不是模型的通用“好看分”，而是图片对指定商业模板的**相对贴合度**。

输出仍保留 0–100 分，以便参与综合评分、排序和阈值筛选，但必须同时显示：

- 模板名称与版本；
- 贴合度等级；
- 可量化子项；
- 相对模板的差距；
- 证据与不确定性。

禁止只显示没有参照系的“商业价值 68 分”。

## 2. 商业上下文模型

模板由四组正交条件组成，避免把渠道、品牌和风格混为一类：

| 维度 | 本模板默认值 |
|---|---|
| 渠道 `channel` | 平台电商 |
| 图位 `placement` | 商品/活动主图 |
| 品牌定位 `brand_positioning` | 白牌至成熟大众品牌 |
| 商业目标 `commercial_objective` | 促销转化、卖点传达、点击 |
| 视觉调性 `visual_tone` | 清晰、直接、促销感、移动端可读 |

后续“大牌旗舰”“内容种草”等应作为不同参数组合，而不是与“直播带货”并列的一维枚举。

## 3. 子指标与权重

| 子指标 | 权重 | 核心问题 |
|---|---:|---|
| 商品主体突出度 | 25% | 首屏是否迅速识别商品、人物是否服务于商品 |
| 卖点表达清晰度 | 20% | 材质、版型、功能或搭配价值是否被有效表达 |
| 促销信息层级 | 20% | 价格、优惠、活动、CTA 是否有明确阅读顺序 |
| 信息可读性 | 15% | 移动端缩略图下文字、数字和关键标签是否可读 |
| 点击动机 | 10% | 是否形成清晰、可信且不过度混乱的进入详情动机 |
| 渠道与图位适配 | 10% | 是否符合平台主图的信息密度与表达习惯 |

总权重：100%。

## 4. 输出口径

### 4.1 分数

`template_fit_score`：0–100，相对当前模板计算。

| 分数 | 贴合度 | 处置建议 |
|---:|---|---|
| 90–100 | 高 | 可作为发布候选，验证期仍需人工复核 |
| 70–89 | 中 | 可用但建议优化主要差距 |
| 0–69 | 低 | 商业表达明显不适合当前模板 |

阈值是 Phase 1 假设，真实数据标定前不得宣称有效。

### 4.2 必须输出

- `template_id`、`template_version`；
- `template_fit_score`、`fit_level`；
- 六个子项分数及证据；
- `relative_gaps`：相对模板的主要差距；
- `commercial_strengths`：已成立的商业表达；
- `assessment_scope`：缺少品牌规范或业务数据时的评估边界；
- 可选修复 Prompt。

示例：

> 相对模板「天猫 / 平台促销主图」贴合度：78/100（中）。商品主体明确，但价格与优惠信息抢占同一视觉层级；移动端缩略图下核心卖点识别较慢。

## 5. 与其他 Skill 的边界

- 商业模板变化只影响商业价值 Skill；
- 真人、摄影、材质评分不随商业模板变化；
- 商品事实错误、人体 Blocker、文字/Logo 错误和合规门禁不受商业高分抵消；
- 综合分可以随商业模板变化，但门禁结果保持确定性。

## 6. 客户校准飞轮

人工改判先写入 `recalibration_log`，不得由单次操作直接修改客户画像。

建议状态：

```text
CAPTURED
→ REVIEWED
→ ACCEPTED / REJECTED
→ PROFILE_APPLIED
```

只有满足以下任一条件才允许更新 `commercial_profile`：

- 同类偏好累计达到约定样本量；
- 双人复核一致；
- 客户管理员明确批准；
- 版本化离线校准通过回归测试。

必须保留模板版本、画像版本、改判前后结论、证据、操作者与时间。

## 7. Phase 1 验收

1. 用户能够选择商业模板；
2. 同一图片切换模板后，商业贴合度与差距可以变化；
3. 客观三层 Skill 和硬门禁保持不变；
4. 人工改判能够进入校准日志；
5. 所有分数明确标注为模板相对分和未标定演示值；
6. 购买模板不得被描述为真实投放效果样本。
