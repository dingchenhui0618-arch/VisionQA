# VisionQA 当前系统统一基线 v0.2

> 日期：2026-08-06  
> 目的：统一首页、工作台、真实模型、数据保存与阿里云上线口径。

## 页面职责

| 地址 | 唯一职责 | 当前状态 |
|---|---|---|
| `/` | 产品说明、四大 Skill、展示真实引擎能力、进入工作台 | 可用 |
| `/workspace` | 建立客户参考、客户画像、批次评分、证据复核、Prompt 与下载 | 本地真实 MVP 可用 |

首页不得展示模拟延迟、模拟通过率或未经验证的准确率。引擎区域现在直接读取 `/api/live-evaluate` 的真实能力信息。

## 当前真实运行模式

- 模型：阿里云百炼 `qwen3-vl-plus-2025-12-19`。
- 批次：每批最多 10 张，单并发。
- 评分：真实模型输出 + 本地规则校验 + 四大 Skill + 商业模板。
- Gate：`HUMAN_REVIEW_REQUIRED`。
- 自动放行：关闭。
- 原图保存：不保存。
- 评估与人工改判：当前验收环境以浏览器保存为主。
- 示例项目：只用于体验，不进入客户上传批次。

## 内核完成度

### 已完成

- Qwen 真实视觉评估适配器与固定模型快照。
- 评分契约、四大 Skill 权重、Blocker Gate、商业六维与修复 Prompt。
- 中文证据归一、图片预检压缩、超时和有限重试。
- PostgreSQL 11 表基线、幂等评估、人工改判、审计和任务状态仓储。
- 阿里云 OSS 私有对象接口、短期签名 URL 与租户路径约束。
- FC 3.0 服务、任务、健康检查和依赖端口骨架。

### 尚未接通

1. FC live composition root 仍未把 OSS、PostgreSQL、Qwen 三个真实端口组合起来。
2. 网站正式账号体系与租户隔离尚未替换内部 ChatGPT 试点认证。
3. 工作台上传尚未走 OSS 私有直传；当前仍由浏览器直接发送给本地评估接口。
4. 真实评估完成后尚未自动写入阿里云 PostgreSQL。
5. 批量任务尚未通过 FC 异步任务执行和恢复。

## 统一上线判断

- `GO_LOCAL_MVP`：真实评分和人工审核闭环可继续验收。
- `GO_STAGING_AFTER_BINDINGS`：完成阿里云真实组合根与资源绑定后可进入 staging。
- `NO_GO_PUBLIC_COMMERCIAL`：账号、租户、OSS、PostgreSQL、FC、限流和合规未全部接通前，不开放正式客户。

## 下一开发顺序

1. 完成阿里云 FC live composition root 与配置验证。
2. 接通 OSS 私有上传和 PostgreSQL 自动持久化。
3. 将单图直调改为可恢复的批次任务。
4. 接入正式账号与租户，再做公开 staging 验收。

当前不需要用户新增 API Key、充值或登录。进入真实云资源接线时，只汇报所需的阿里云登录、资源授权、密钥或费用操作。
