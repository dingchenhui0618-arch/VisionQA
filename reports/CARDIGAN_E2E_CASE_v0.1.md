# VisionQA 灰色针织开衫端到端案例 v0.1

> 日期：2026-08-27
> 证据等级：`SYNTHETIC_INTERNAL_TEST_ONLY`

## 输入

- 内置 ImageGen 生成 SKU 四视图真值：暖浅灰细罗纹短款开衫、四颗深灰纽扣、穿着者左胸一枚黑色五瓣花刺绣。
- 内置 ImageGen 生成错误模特图：同款全身模特图，但穿着者右胸额外复制一枚刺绣。
- 素材目录：`data/synthetic_demo_sku_gray_cardigan_v0.1/`。

## 实际流程与结果

| 阶段 | 实际结果 | 证据边界 |
|---|---|---|
| SKU 真值 | 图片真值 + 结构化事实已建立 | 合成内部样例 |
| 第一次诊断 | 漏掉重复刺绣，误报 Logo 位置、下摆与袖长 | 不可用于修正 |
| 真值语义修正后诊断 | 识别重复刺绣，但误报纽扣数量 | 部分改进，仍不可自动执行 |
| 结构化 SKU 事实诊断 | 正确识别右胸多余刺绣与四颗纽扣，但误报左胸正确刺绣缺失 | 自动诊断仍需人工确认 |
| 人工确认问题 | 锁定“只删除穿着者右胸复制刺绣” | 当前必要 Gate |
| Qwen Image 3 修正 | 单次成功，89.248 秒，1672×2508，0 重试 | 实际费用待账单核验 |
| 自动漂移 Gate | `ALLOW_HUMAN_REVIEW` | 只排除大幅构图漂移 |
| 人工复验 | 目标修复、正确刺绣、四纽扣与全身构图保留 | 实现方复验，独立 QA 因工具故障未完成 |
| 4K 交付副本 | 2560×3840 Lanczos3 本机重采样 | `detail_reconstruction=false` |

## 产品结论

本案例证明 VisionQA 的“商品真值 → 人工确认问题 → 受控改图 → 前后对比 → 漂移 Gate → 人工复验”链路可运行。它同时否定了“单次视觉诊断可以直接自动决定修图”的假设：即使加入权威真值和结构化事实，模型仍产生可见假阳性。

当前正确产品结构是：

`自动候选问题 + 用户/美工确认 → 受控修正 → 自动大漂移拦截 → 人工终审`

自动放行继续关闭。下一步真实测试应记录：主问题发现率、假阳性数量、一次修正后 PS 收尾分钟数、非目标漂移和实际单次费用。
